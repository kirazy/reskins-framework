Version: 0.2.1
Date: ????
  Features:
    - Added setting "Show tier labels on belts", default on, which shows or hides the tier labels of transport belts, underground belts, splitters, and loaders.
    - Added `tiers.assign_icons_with_tier_labels`, which assigns a table of icon definitions from Artisanal Reskins: Sprite Utils to the prototypes of one type, each with the tier label of its `tier`, and leaves out the tier labels of the icons it reads from other prototypes.
  Changes:
    - `tiers.icon_assignment_with_tier_labels` now takes every form of an icon definition, including `sources` and `label`, with an optional `tier`, default 0; it composes the icon in the icon defaults type of the prototype and returns `pictures` as an array of sprites.
    - `tiers.are_tier_labels_shown_for` now returns `false` for technologies, and technologies are no longer given tier labels.

Version: 0.2.0
Date: 2026-11-01
  Features:
    - Updated for Factorio 2.1
    - Added setting "Show tier labels in world", default off.
    - Added `tiers.icon_assignment_with_tier_labels`, which is the preferred way to package an icon with tier labels for assignment and manages compliance with the current user settings and complexities around the pictures field for in-world icons.
    - Added `tiers.tier_label_group`, the icon composition group for tier labels.
    - Added support for icon compositions from Artisanal Reskins: Sprite Utils.
    - Added `api/validation` with preconfigured validators for types used by the framework.
  Changes:
    - `tiers` functions now validate parameters, and will throw on invalid inputs with descriptive messages.
    - `tiers.add_tier_labels_to_named_prototype` requires the named prototype to exist.
    - Removed `get_deferrable_icon_for_prototype_with_added_tier_labels`; use `tiers.icon_assignment_with_tier_labels` instead and assign the result.
